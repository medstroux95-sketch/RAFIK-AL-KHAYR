# منصة وكالة رفيق الخير للسفر والسياحة (Rafiq Al Khair)
### المنصة الفاخرة والمتطورة لحجز وإدارة رحلات العمرة بالمغرب

منصة تجارية إلكترونية متكاملة بنيت خصيصاً لوكالة **رفيق الخير للسفر والسياحة**، تجمع بين الهوية البصرية الإسلامية الراقية، الفخامة، والسرعة الفائقة، وتتيح للمعتمرين استكشاف عروض العمرة ومقارنتها وحجزها إلكترونياً، مع لوحة تحكم إدارية ومحرر بصري CMS ونظام تتبع وإشعار واتساب ذكي.

## 🌟 مميزات وأقسام المنصة

1. **الواجهة الأمامية الفاخرة (`/`)**:
   - شريط علوي معتمد يضم الهاتف المباشر (`0662574740`)، الواتساب، والترخيص السياحي.
   - قسم Hero ملكي مع خلفية الكعبة المشرفة وتأثيرات الإضاءة الروحانية وعناوين الهوية.
   - محرك بحث متقدم لرحلات العمرة حسب المدينة (الدار البيضاء، الرباط، مراكش...)، الموسم، وعدد المسافرين.
   - بطاقات العروض التفاعلية مع إمكانية التبديل بين أنواع الغرف ومشاهدة السعر الفوري بالدرهم المغربي.
   - جدول الرحلات القادمة ومستوى توفر المقاعد.
   - 6 أسباب لاختيار الوكالة، استعراض الفنادق والمسافات عن الحرمين، آراء المعتمرين الموثقة، والأسئلة الشائعة.
   - نموذج طلب استشارة وعمرة مخصصة.

2. **كتالوج العروض الشامل (`/packages`)**:
   - فلترة ديناميكية حسب الفئة (رمضان، عبر تركيا، اقتصادي، متوسط).
   - ترتيب فوري حسب السعر ومدة الإقامة.
   - عداد للمقاعد المتبقية لكل رحلة.

3. **صفحة تفاصيل الرحلة (`/packages/[id]`)**:
   - معرض صور عالي الدقة، جدول تفصيلي يومي للرحلة، تفاصيل الفنادق والطيران، وقائمة المشمول وغير المشمول.
   - حاسبة تفاعلية للأسعار حسب نوع الغرفة وعدد المعتمرين.
   - زر واتساب ذكي يرسل تفاصيل البرنامج المختار مباشرة لمستشار الوكالة.

4. **نظام الحجز الإلكتروني المتكامل (`/booking/[id]`)**:
   - معالج من 4 خطوات واضحة وبسيطة.
   - دعم خيار دفع العربون (30%) أو الأداء الكامل (100%).
   - دعم أكواد الخصم (`RAMADANMUBARAK` = خصم 1,000 د.م).
   - وسائل دفع متعددة: التحويل البنكي (مع إظهار RIB التجاري وفا بنك)، الدفع في مقر الوكالة، والدفع الإلكتروني الآمن بالبطاقة البنكية.
   - إصدار فوري لرقم حجز فريد (مثال: `RAK-2026-XXXX`)، وصل حجز قابل للطباعة، ورابط متابعة مباشر.

5. **بوابة تتبع الحجز (`/track`)**:
   - تتيح للمعتمر إدخال رقم الحجز وهاتفه لمعرفة حالة الطلب والدفعات المسددة والمتبقية والتحديثات.

6. **لوحة التحكم الإدارية الكاملة ومحرر CMS (`/admin`)**:
   - إحصائيات ومؤشرات مالية دقيقة محسوبة مباشرة من قاعدة البيانات.
   - إدارة البرامج (إضافة، تعديل الأسعار، تغيير التواريخ، حذف).
   - إدارة الحجوزات (تعديل الحالة، تسجيل دفعات إضافية، إصدار إيصالات).
   - محرر الموقع المرئي لتعديل اسم الوكالة، الهواتف، الحساب البنكي، ونصوص الواجهة بدون برمجة.
   - سجل العمليات والتدقيق (Audit Logs).

7. **زر واتساب الذكي العائم**:
   - رقم معتمد: `0662574740` (دولي: `+212662574740`).
   - رسائل سياقية مجهزة مسبقاً حسب الصفحة والبرنامج لتسهيل تواصل العميل.

## 🛠 التقنيات المستخدمة

- **الواجهة الأمامية**: Next.js 14 (App Router) مع React 18 وTypeScript.
- **التنسيق والتصميم**: Tailwind CSS مع لوحة ألوان إسلامية فاخرة (الأخضر الزمردي والذهبي الهادئ) ودعم كامل للـ RTL والخطوط العربية (Cairo & Amiri).
- **قاعدة البيانات**: محرك بيانات علائقي متكامل مع كتابة ذرية آمنة (Atomic Writes) في `src/data/db.json` مع طبقة مستودع TypeScript في `src/lib/db.ts`.
- **الأمان**: تشفير البيانات، التحقق من السعة في جانب الخادم (Server-Side Capacity Check)، عزل أرقام البطاقات المصرفية، وفهارس تدقيق العمليات.
